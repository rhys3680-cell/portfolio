# 윤창기 포트폴리오

업무 흐름을 분석해 데이터 파이프라인, AI 제품, 자동화 도구로 바꾸는 AX 개발자의 포트폴리오입니다.

## 사례

- AI 리테일 분석: 자연어 질의, SSE 보고서, 대용량 렌더링 최적화
- 패션 배분 관리: 초도·점간 배분 시뮬레이션과 인증 인프라
- ERP UI 자동화: API 없는 Windows ERP와 DB의 양방향 파이프라인
- FDS: IEEE-CIS 데이터 파이프라인과 운영 임계값 정책
- Alexandria: 로컬 우선 개인 AI 데스크톱

회사 프로젝트는 고객사 코드와 데이터를 공개하지 않고 문제, 기여, 검증 가능한 결과만 설명합니다.

## 실행

```bash
pnpm install
pnpm dev
```

Next.js 16, React 19, TypeScript, Tailwind CSS로 만들었습니다.
